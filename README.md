# Qinghua Sun — Portfolio

Source for [my portfolio website](https://qinghua-github-io.vercel.app/), which highlights selected AI agent, ML systems, and software engineering projects.

- `index.html`: responsive, dependency-free portfolio page
- `resume.pdf`: current one-page U.S. internship resume

The site links to the project repositories for implementation details and to [my LinkedIn](https://www.linkedin.com/in/qinghua-sun-23618a392/) for professional experience.

## Local preview

Open `index.html` in a browser, or serve this directory with a static file server. The page does not need a build step.
